### 数字音频基础：采样率、位深与声道

> 状态：经典架构 ｜ 音频处理基本常识

音频本质是连续声波经采样与量化得到的离散数字信号。**采样率（Sample Rate）**决定了能够还原的最高频率（根据奈奎斯特定理，最高频为采样率的一半）：常见语音识别（ASR）使用 16kHz；普通 TTS 常用 24kHz / 32kHz；专业高保真音乐与歌声克隆必须使用 **44.1kHz 或 48kHz**。

**位深（Bit Depth）**决定了音频的动态范围：16-bit 具备 96dB 动态范围，是绝大多数语音模型输入的标准；24-bit/32-bit float 则用于母带录音与防止削波（Clipping）。在模型训练与推理中，音频一律转为单声道（Mono）以消除立体声相位抵消误差。

**常用采样率规格速查**

| 采样率 | 常见应用场景 | 典型代表模型 |
|---|---|---|
| 16,000 Hz (16k) | 语音识别 (ASR)、声纹比对 | Whisper, FunASR, SenseVoice |
| 24,000 Hz (24k) | 轻量/早期快速 TTS | ChatTTS, MeloTTS, Edge-TTS |
| 32,000 Hz (32k) | 平衡型零样本语音合成 | GPT-SoVITS v1, CosyVoice 1 |
| 44,100 / 48,000 Hz (48k) | 高保真 AI 翻唱与专业歌声克隆 | RVC v2, So-VITS-SVC 4.0/5.0, GPT-SoVITS v2/v3 |

### 从文本到波形：现代 TTS 的三段式核心链路

现代主流语音合成并非一步到位，而是经历『文本处理 → 声学特征预测 → 声码器波形还原』三段式结构：

**① 文本前端（Text Frontend / G2P）**：将原始汉字/英文转为音素（Phoneme），处理多音字（如『还钱』vs『还有』）、数字缩写（如『2026年』读作『二零二六年』）及标点停顿。

**② 声学模型（Acoustic Model）**：输入音素序列与提示音频特征（Prompt），预测对应的中层声学表征（通常是 80 维梅尔频谱 Mel-Spectrogram，或离散语音 Token）。现代模型（如 GPT-SoVITS、CosyVoice）采用自回归或流匹配机制完成这一步。

**③ 声码器（Vocoder）**：将梅尔频谱还原为人类耳朵听到的时域声波（Waveform）。经典声码器包括 HiFi-GAN、BigVGAN、Vocos 等，决定了最终声音的空气感与清晰度。

> 【声音合成核心公式】文本 (Text) → G2P音素 (Phonemes) + 提示音频 (Prompt) → [声学模型] → 梅尔频谱 (Mel) / 离散Token → [声码器 Vocoder] → 实际听到的音频 (Waveform)

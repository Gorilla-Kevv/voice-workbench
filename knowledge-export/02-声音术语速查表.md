# AI 声音知识图谱 · 术语速查表（10 条）

| 术语名称 | 类别 | 核心概念与实战解释 |
|---|---|---|
| **Zero-Shot (零样本)** | 概念 | 无需对模型权重进行任何梯度更新或微调，仅提供几秒参考音频即刻复刻音色的能力。 |
| **Mel-Spectrogram (梅尔频谱)** | 声学 | 模拟人耳非线性听觉感知特性的时频图表示，是声学模型与声码器交互的核心中层特征。 |
| **Vocoder (声码器)** | 架构 | 将中层梅尔频谱或特征表征还原为高保真时间域波形（声波）的神经网络组件（如 HiFi-GAN）。 |
| **F0 / Pitch (基频与音高)** | 声学 | 声带振动的基频频率，决定了声音听觉上的高低音调；在歌声克隆与情绪表达中至关重要。 |
| **RMVPE** | 算法 | 深度神经网络驱动的高精度抗噪人声基频提取算法，在复杂音频和背景微噪下音高提取极稳。 |
| **Flow Matching (流匹配)** | 架构 | 新一代非自回归生成架构，基于常微分方程 ODE 建模噪声到语音的连续演化，推理快且无复读幻觉。 |
| **LUFS (响度单位)** | 工程 | 针对人耳感知加权的标准化响度衡量单位；语音数据集通常标准化至 -16 到 -20 LUFS。 |
| **RTF (实时率)** | 指标 | Real-Time Factor，合成音频耗时与音频实际播放时长的比值。RTF < 1.0 即代表可实现实时合成。 |
| **Index Rate (特征检索比)** | 调优 | RVC 中控制从目标人声特征库聚类检索相似特征的融合比例，用于消除源说话人音色泄露。 |
| **G2P (字素转音素)** | 前端 | Grapheme-to-Phoneme，将自然语言字符转换为国际音标或特定拼音音素序列的前端处理模块。 |

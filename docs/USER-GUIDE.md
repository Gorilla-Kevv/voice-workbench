# 本地语音工作台 · 使用手册

本手册面向**使用者**，覆盖从安装启动到训练、合成、排障的完整流程。

> 项目定位：**只在本地运行**。所有音频、语料、模型权重都留在本机，不依赖任何线上服务器（使用云端模型功能时除外，那时数据会走厂商接口，手册中已逐处标注）。

## 1. 快速开始

### 1.1 环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows（已适配）；Linux / macOS 可用 `scripts/start.sh` |
| Node.js | ≥ 18.17（推荐 20+） |
| Python | 3.9 ~ 3.12 —— **推荐直接用整合包自带的 `runtime/python.exe`**，里面已装好 torch |
| 显卡 | 建议 NVIDIA 8GB+ 显存（CPU 也能跑推理，但很慢；训练强烈建议 GPU） |
| GPT-SoVITS | 整合包放在项目同级目录，例如 `GPT-SoVITS-v2pro-20250604/` |

### 1.2 安装

```bash
npm run install:all
```

安装三处依赖：项目根目录（`concurrently`）、`app/`、`server/`。Python 侧依赖由本地服务自己处理，无需手动 `pip install`。

### 1.3 启动

**Windows 用户直接双击项目根目录的 `start.bat`。**

它会自动完成：检查 Node 版本 → 首次运行时安装依赖并做环境体检 → 启动三个进程 → 打开浏览器。

终端模式：

```bash
npm run dev        # 并行启动：本地模型服务 + 网关 + 前端
npm run dev:cloud  # 只用云端模型：只起网关 + 前端
npm run dev:sovits # 只起本地模型服务（想让它常驻时用）
```

启动后访问 **http://localhost:5173**。

### 1.4 验证安装

```bash
npm run sovits:check
```

退出码 `0` 表示就绪。它会明确告诉你：是否找到整合包、用的是哪个解释器、显卡型号、缺哪些依赖、以及下一步该做什么。

同一份信息在运行中也能查：`GET http://127.0.0.1:9881/health`。

### 1.5 启动后会发生什么

| 端口 | 进程 | 说明 |
| --- | --- | --- |
| 5173 | 前端（Vite） | 你看到的界面 |
| 8787 | Node 网关 | 代理本地服务、封装云端接口、托管构建产物 |
| 9881 | 本地模型服务 | Python 进程，持有模型 |

首次启动的等待时间：Python 侧 `import torch` 约 10~20 秒，模型预加载再花 30~90 秒。**这期间页面可正常打开**，侧栏会显示「正在连接」，服务就绪后自动变绿 —— 不需要刷新页面。

## 2. 核心概念

### 2.1 两条模型路线

| | **MiMo（云端）** | **GPT-SoVITS（本地）** |
| --- | --- | --- |
| 部署 | 无需本地算力，填 API Key 即用 | 需要本机 GPU 与整合包 |
| 音色来源 | 官方预置 9 个音色 | **没有内置音色**，必须自己导入参考音频 |
| 音色设计 | ✅ 用文字描述凭空造音色 | ❌ 不支持 |
| 声音克隆 | ✅ | ✅（5 秒音频即可） |
| 专属微调 | ❌ | ✅ |
| 语种 | 中文（含方言）、English | 中 / 英 / 日 / 韩 / 粤，且支持跨语言 |
| 数据流向 | 音频走云端接口 | **全程不出本机** |

**怎么选：**

- 想快速出声、不想装环境 → 路线 A（云端）
- 要克隆自己的声音、做日语/韩语、批量做有声书、或数据不能外传 → 路线 B（本地）

### 2.2 几个必须分清的概念

| 概念 | 是什么 | 关键点 |
| --- | --- | --- |
| **音色** | 一个人的声音特质 | 本地模型里，一个音色 = 一段参考音频 + 它的逐字文本 |
| **参考音频** | 让模型模仿的那段录音 | **3~10 秒**（官方推荐 5 秒）、单人、干净、无背景音 |
| **提示文本** | 参考音频里说了什么 | **必须逐字一致**，错一个字都会被学进去 |
| **参考音频语种** | 参考音频说的是哪种语言 | 与「合成文本的语种」是两回事，可以不同（跨语言合成） |
| **语料** | 训练用的成批素材 | 单人、安静、无背景音乐；1 分钟以上才能微调 |
| **训练清单（.list）** | 音频与文本的对应表 | 每行：`音频路径|说话人|语种|文本` |

### 2.3 界面里的术语提示

界面上**带灰色虚线下划线**的词都是专业术语：

- **桌面**：鼠标停在上面即显示解释（也可键盘 Tab 聚焦）
- **触屏 / 手机**：点一下弹出

解释分三部分：它是什么 → 它影响什么 → （部分术语）一个具体示例。

页面**右侧边缘**还有一条竖条，鼠标移到窗口最右侧会展开「**官方推荐流程**」—— 这是 GPT-SoVITS 开发者给出的标准步骤，边做边看，不必在文档和界面之间来回切。

## 4. 路线 A：MiMo 云端模型

### 4.1 配置密钥

1. 打开 **设置** 页
2. 在「MiMo API Key」处填入密钥（获取地址：https://platform.xiaomimimo.com/console/api-keys）
3. 密钥只存在**浏览器本地**，不会上传到本项目服务端

> 服务端也可以统一配置 `MIMO_API_KEY`（在 `server/.env` 中），配置后所有用户都不必再填。

### 4.2 通用语音合成

1. 进入「通用语音合成」
2. 在「预置音色」里选一个（如「冰糖」「茉莉」）
3. 输入文本
4. 可选：加风格标签、方言标签、语气指令
5. 点击合成

**MiMo 独有的控制方式**（这些对本地模型无效）：

| 功能 | 说明 |
| --- | --- |
| 风格标签 | 写在文本开头的情绪标记，如 `(开心)` |
| 方言标签 | `(粤语)` 等地域腔调 |
| 音频标签 | 插在句中的细粒度标记，控制停顿、语气 |
| 唱歌模式 | 把歌词以歌唱方式演绎 |
| 语气指令 | 一句话描述想要的演绎方式，不出现在语音里 |

### 4.3 音色设计

用一句描述生成全新音色，例如「沉稳的中年男声，语速偏慢，适合纪录片旁白」。这是**云端独有的能力**。

### 4.4 声音克隆

上传一段样本音频即可复刻音色。注意云端克隆时**音频会上传到厂商接口**；若素材敏感，请改走本地路线。

## 5. 路线 B：GPT-SoVITS 本地模型

### 5.1 第一步：导入音色（必做）

本地模型**没有内置音色**，第一步永远是导入参考音频。

1. 进入「音色库」→ 新建音色
2. 上传一段 **3~10 秒**的音频（推荐 5 秒左右的切分片段）
3. 填写**提示文本** —— 这段音频里逐字说了什么
4. 选择**参考音频语种**
5. 保存

**素材要求（决定成败）：**

- ✅ 单人说话，无背景音乐、无混响、无底噪
- ✅ 说话自然、音量稳定
- ❌ 不要带 BGM、不要有回声、不要多人对话

页面会回放这段音频，上传前先听一遍。

### 5.2 第二步：合成

**单条** —— 去「通用语音合成」，把模型切到 GPT-SoVITS，选中音色，输入文本合成。

**批量** —— 去「批量合成」：

1. 粘贴文本清单（每行一条），或导入 `txt` / `csv`
2. 选择音色
3. 可选：展开高级参数（切分方式、语速、temperature、复读惩罚、分桶、并行推理）
4. **先点「试听首条」**确认音色，再点「开始批量合成」
5. 完成后：逐条试听 / 下载 / 下载 ZIP（含 `audio/` + `manifest.json` + `index.csv`）

单条失败不影响其余条目，失败原因会留在结果列表里。

### 5.3 第三步（可选）：训练专属音色

零样本克隆够用就先不训练。想要更稳、更像，走训练流程（下一节）。

## 6. 参数配置详解

### 6.1 官方推荐流程（8 步）

来自 GPT-SoVITS 开发者，界面右侧可随时查看。摘要：

| 步骤 | 做什么 | 要点 |
| --- | --- | --- |
| 1 | 人声分离 | 素材有 BGM/噪声才需要；官方推荐 BS 模型；切分前删掉 other 背景音 |
| 2 | 语音切分 | 参数默认不动；切出来全偏长就把 300 改成 100~200；删掉 >15 秒的超长条 |
| 3 | 语音识别 | 中文/粤语用达摩 ASR，其它语种用 Faster Whisper |
| 4 | 标注校对 | 可跳过；但读音怪异时回来校对最有效 |
| 5 | 训练集格式化 | 只建议 V2 Pro / V2 Pro Plus |
| 6 | 微调训练 | 参数默认；**先 SoVITS 后 GPT**；DPO 不要开 |
| 7 | 推理选权重 | E = 轮数（选最大），S = 步数 |
| 8 | 合成设置 | 参考音频 5 秒左右；语种选参考音频的语种 |

### 6.2 训练页阶段开关

| 阶段 | 何时开 |
| --- | --- |
| 语料导入 | 始终 |
| **人声分离（UVR5）** | 素材带 BGM / 混响 / 延迟 |
| 语音降噪 | 有明显底噪（注意：该模型需联网下载，本地无缓存时可能失败） |
| 音频切分 | 长录音必须开；素材已是 5~15 秒小段可关 |
| 语音转文本 | 没有现成文本时开 |
| 生成训练清单 | 通常开 |
| 格式化训练集 | 始终开（含文本特征 / HuBERT / 说话人向量 / 语义 Token） |
| GPT（语义）训练 | 微调时开 |
| SoVITS（声学）训练 | 微调时开 |

### 6.3 切分参数（8 个）

默认值取自官方 WebUI，**绝大多数情况不用改**。

| 参数 | 默认 | 何时调 |
| --- | --- | --- |
| threshold 静音阈值 | -34 | 环境噪声大 → 调低（-40） |
| min_length 最小长度 | 4000 | 想保留短句 → 调小 |
| min_interval 最短间隔 | 300 | **切出来全部偏长 → 改成 100 或 200** |
| hop_size 音量曲线精度 | 10 | 一般不动（越小越慢） |
| max_sil_kept 静音保留 | 500 | 想更紧凑 → 调小 |
| max 归一化峰值 | 0.9 | 一般不动 |
| alpha 归一化混合 | 0.25 | 1=完全拉平，0=保持原音量 |
| n_parts 切片进程数 | 1 | 本机单显卡保持 1，避免抢资源 |

### 6.4 ASR 参数

| 项 | 建议 |
| --- | --- |
| 后端 | 中文/粤语 → FunASR（达摩）；其它语种 → Faster Whisper |
| 模型尺寸 | 越大越准但越慢；中文用 large，其它用 medium 或 large-v2/v3 |
| 精度 | Faster Whisper：显存紧张 float16/int8，求准 float32。**FunASR 官方注明该参数尚未接入，选了不生效** |
| 常驻模型 | 连续转写很多条时开，更快但持续占显存 |

### 6.5 训练超参

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| GPT epoch | 15 | 语料少（1~5 分钟）建议 15~30 |
| GPT batch | 6 | 显存不足降到 1~4 |
| SoVITS epoch | 8 | 不像本人时优先加这个 |
| SoVITS batch | 6 | 同上 |
| LoRA rank | 32 | 仅 v3/v4；语料少降到 8~16 |
| GPU 编号 | 0 | 多卡可填 `0-1` 分片 |

**官方建议：参数全部保持默认**（已按显存自动调整）。

### 6.6 合成参数

| 参数 | 作用 | 建议 |
| --- | --- | --- |
| 切分方式 | 长文本怎么断句 | 长文本 `cut5`，短句 `cut0` |
| 语速倍率 | 整体快慢 | 1.0 原速；改了音色会轻微变化 |
| temperature | 随机程度 | 要稳定 → 调低；要自然 → 略调高 |
| top_k / top_p | 采样收窄 | 通常二选一调整 |
| repetition penalty | 抑制复读 | 卡字/复读 → 调高（如 1.5） |
| 分桶 | 长度相近的批量推理 | 更快；语速 ≠ 1.0 时自动关闭 |
| 并行推理 | 同时处理多段 | 更快但更吃显存 |
| 变体推理 | 官方称提速约一倍 | 显卡弱无收益；V3/V4 无此选项 |

## 7. 常见任务操作流程

### 7.1 克隆自己的声音（最快路径）

1. 录一段 **5 秒**干净独白
2. 音色库 → 新建音色：上传 + 填逐字文本 + 选语种
3. 通用合成 → 模型切到 GPT-SoVITS → 选中音色 → 输入文本 → 合成

约 2 分钟完成。效果不满意再考虑训练。

### 7.2 训练专属音色（完整流程）

1. **准备素材**：单人、安静、1 分钟以上有效语音（5 分钟以上更好）
2. 训练页 → 填实验名 → 选语料目录
3. 按素材情况开阶段：带 BGM 开「人声分离」；长录音开「音频切分」；没文本开「语音转文本」
4. 点「**预检计划**」—— 先看看每一步会执行什么，参数错了当场就能发现
5. 点「开始训练」，观察阶段进度与日志
6. 训练完成后，权重写入 `GPT_weights_<版本>/` 与 `SoVITS_weights_<版本>/`
7. 合成时会自动优先使用最新训练的权重

### 7.3 做有声书

1. 音色库准备好音色
2. 批量合成 → 粘贴/导入整章文本（每行一条）
3. 「试听首条」确认
4. 开始批量合成 → 下载 ZIP
5. ZIP 里的 `index.csv` 可用 Excel 打开，便于对号入座

**提示**：长句子用 `cut5` 切分更稳；遇到卡字把复读惩罚调到 1.4~1.6。

### 7.4 翻唱（歌声转换）

1. 进入「歌声转换」
2. 上传歌曲
3. 开「人声分离」（**带伴奏必须开**，否则伴奏会被算进人声）
4. 选目标音色
5. 长歌建议开「长音频自动切分」（避免 8GB 显存峰值溢出）
6. 开始转换

### 7.5 变声

1. 进入「语音变声」
2. 上传源音频（说话/配音干声，建议 ≤5 分钟）
3. 选目标音色
4. 按需设 F0 方法与变调（半音）
5. 开始 → 完成后可 A/B 对比原声与变声

### 7.6 批量转写素材（ASR）

1. 进入「语音转文本」
2. 选场景预设 → 后端 / 模型尺寸 / 语种
3. 上传音频或填语料目录
4. 设置数据集名称
5. 开始转写 → 产出 `.list` 清单，可直接用于训练

### 7.7 校正 ASR 的错字

转写完成后，若任务产出了清单，训练页会出现「**标注校对**」面板：

- 左边播音频，右边改文本
- 可标记「丢弃这条」（音频有问题时）
- 保存后点「用这份清单训练」—— 会自动填入清单路径**并关闭语音转文本**，避免下一轮又被 ASR 覆盖

> 官方认为这一步非常耗时、收益有限，**可以跳过**。但如果合成结果里某些字读音怪异，回来校对对应条目是最有效的排查手段。

## 8. 进阶功能

### 8.1 UVR5 人声分离

在训练页开启，模型从整合包扫描（只列真实存在的）：

| 模型 | 用途 |
| --- | --- |
| HP2_all_vocals | 保留人声（无和声）—— 默认 |
| HP5_only_main_vocal | 仅保留主人声（有和声时） |
| VR-DeEchoNormal / Aggressive | 去延迟 |
| VR-DeEchoDeReverb | 去延迟 + 去混响（耗时约 2 倍） |
| onnx_dereverb_By_FoxJoy | MDX-Net 去混响（双通道有效，不能去单通道） |
| BS-RoFormer | **官方首选**，但本机缺 `.yaml` 配置文件，暂不可用 |

输出人声与伴奏两份，**只保留人声进入后续流程**。

### 8.2 预训练权重自定义

设置里留空即用整合包自带权重。想接着自己训过的权重继续练，或换社区权重时，在训练页「预训练权重」处填绝对路径。路径不存在会在**预检阶段**就报错，不会拖到训练中途。

### 8.3 权重与版本

- 版本：**官方只建议 V2 Pro / V2 Pro Plus**（界面上已标注「官方推荐」）
- 权重文件名：`E` = 训练轮数，`S` = 步数。例 `my-voice_e16_s2160.pth` → 第 16 轮第 2160 步
- 官方建议选 **E 最大**的那个

### 8.4 音色工坊（变声页）

两条缓解「换音色就要重训」的路径：

- **音色融合**：把两个权重按比例混合，零训练，几分钟试出方向
- **LoRA 微调**：只训约 4% 参数，产物几 MB，可热切换

## 9. 注意事项

### 9.1 素材质量决定上限

模型只能逼近素材的质量。以下会直接毁掉结果：

- 带背景音乐 → 必须先做人声分离
- 混响/回声 → 去混响
- 底噪 → 降噪
- 多人对话 → 分开处理
- 参考音频 >10 秒或 <3 秒 → 裁剪到 5 秒左右

### 9.2 提示文本必须逐字一致

错一个字都会被学进模型，表现为**某些字读音怪异**，而且事后极难定位是转写错了还是模型学歪了。

### 9.3 语种的两个概念

- **参考音频语种** = 参考音频说的是什么语言
- **合成语种** = 你要合成的文本是什么语言

两者不同 = 跨语言合成（如中文音色读日语）。官方特别强调这一点容易搞混。

### 9.4 显存管理

- 训练会**独占显卡**，期间不要同时批量合成
- 显存不足时优先降 batch、再关并行推理、最后开梯度检查点
- 8GB 显卡：处理长歌要开「长音频自动切分」
- 半精度（float16）在 8GB 卡上基本必须开

### 9.5 数据安全

- 本地模型路线：**数据不出本机**
- 云端模型（MiMo）：音频会走厂商接口，敏感素材请走本地
- 密钥只存浏览器本地

### 9.6 合规

克隆他人声音需获得明确授权；禁止用于伪造身份、诈骗等违法用途。

## 10. 故障排查

### 10.1 启动类

| 现象 | 排查 |
| --- | --- |
| 双击 `start.bat` 窗口一闪就没 | 前置检查失败。脚本出错时会暂停等待按键；若窗口直接消失，多半是文件被改成 UTF-8（**必须是 ANSI/GBK**）。在终端里执行 `start.bat` 可看到完整报错 |
| 提示端口 8787 / 5173 被占用 | 上次的服务没关干净。脚本会打印占用进程 PID，`taskkill /F /PID <PID>` |
| 侧栏一直「正在连接」超过 90 秒 | 本地服务真没起来，看终端 `[sovits]` 段的输出；或跑 `npm run sovits:check` |
| `npm run dev` 报 `concurrently 不是内部或外部命令` | 根依赖没装，执行 `npm install` |

### 10.2 合成类

| 现象 | 原因与处理 |
| --- | --- |
| **「不支持合成语种 undefined」** | 音色的「参考音频语种」存成了脏数据。服务启动时会自动纠正为 `zh`；若仍出现，到音色库把该音色语种重选一次 |
| **「未知模型版本 v2proplus」** | 已修复（前后端双向归一化）。若复现请贴版本号 |
| 合成失败弹窗反复出现 | 已修复（依赖改为具体 error）。若复现请截图 |
| 页面一片全白 | 现在会显示「页面渲染出错」卡片，含错误信息与调用栈。按卡片提示操作，或点「重置本地配置后重载」 |
| 某些字读音怪异 | 提示文本/标注有错字。到标注校对里改对应条目 |
| 出现卡字、复读 | 复读惩罚调到 1.4~1.6 |
| 声音不像本人 | 换更干净的参考音频；或增加 SoVITS 训练轮数 |
| 训练期间合成被拒绝 | 正常：训练独占显卡。等训练结束或先取消 |

### 10.3 训练类

| 现象 | 处理 |
| --- | --- |
| 预检报「缺少 UVR5 模型」 | 确认整合包 `tools/uvr5/uvr5_weights` 里有 `.pth / .ckpt / onnx` 权重 |
| BS 模型选不了 | 缺同名 `.yaml`，先用 HP2 / HP5 |
| 切分结果全部偏长 | min_interval 从 300 改成 100 或 200 |
| 降噪阶段失败 | `tools/denoise-model/` 是空目录，模型需联网下载。改用 UVR5 的 DeEcho / ONNX 去混响 |
| 显存不足（OOM） | 降 batch → 关并行 → 开梯度检查点 → 关闭 GPT 或 SoVITS 只训一个 |
| 训练中途看不到进度 | 切换页面不会丢（会自动恢复轮询）。若仍卡住，查任务日志 |

### 10.4 快速自检清单

```bash
npm run typecheck      # 类型检查
npm run sovits:check   # 环境体检（退出码 0 = 就绪）
npm run build          # 构建
```

浏览器打开 http://localhost:5173，控制台应无报错。

## 11. 最佳实践

### 11.1 素材

- 录音环境：安静小房间，远离墙面（减少混响）
- 用耳机麦或指向性麦克风
- 一次录 5~10 分钟，再切分成 5~15 秒小段
- 保持音量稳定，避免忽大忽小

### 11.2 参考音频

- **5 秒左右**最佳
- 选情绪平稳、发音清晰的句子
- 避免「嗯」「啊」等语气词开头

### 11.3 训练

- 先跑「预检计划」再提交 —— 参数错误当场可见
- 参数保持默认，不要随手调
- 微调前先确认素材已处理干净（分离/切分/转写）
- 训练顺序按官方建议：**先 SoVITS 后 GPT**
- DPO 不要开

### 11.4 合成

- 批量合成前一定先「试听首条」
- 长文本用 `cut5`；短句用 `cut0` 更连贯
- 一次提交几百条，比反复点击高效得多
- 结果用 ZIP 下载，保留 `index.csv` 便于对号入座

### 11.5 迭代

- 先零样本克隆试效果，不够再训练
- 训练后 A/B 对比，确认是否真的变好
- 每次只改一个变量，便于定位影响

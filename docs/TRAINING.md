# 本地训练指南

本文面向「我有一段自己的录音，想得到一个专属音色」这个真实需求。
所有训练都在本机完成，不需要联网上传任何素材。

> 命令与阶段的实现细节见 [`GPT-SOVITS.md`](GPT-SOVITS.md)。
> 第一次用建议先跑通「零样本克隆」（5 秒素材即可），确认整条链路可用后再来训练。

---

## 一、先判断：你真的需要训练吗

| | 零样本克隆 | 少样本微调 |
| --- | --- | --- |
| 素材要求 | 3~10 秒干净人声 | 建议 **1 分钟以上**有效语音，越多越好 |
| 耗时 | 秒级 | 十几分钟到数小时 |
| 相似度 | 尚可，音色会随句子漂移 | 明显更高，稳定性好得多 |
| 跨语言 | 可用，但口音不稳 | 更稳 |

经验值：**1 分钟语料 + 8~15 epoch** 就能得到明显优于零样本的结果；
5 分钟以上会进入「听不太出与原声差异」的区间。

---

## 二、素材准备（决定上限的一步）

训练质量的上限由素材决定，模型只能逼近它。

### 音频要求

- **单人**：不要有第二个人说话、不要有和声；
- **无背景音乐、无混响**：混响会被学成「空间感」，表现为声音发闷；
- **底噪尽量低**：有底噪时先用「语音降噪」阶段；
- **采样率任意**（官方会统一重采样到 32k），但建议 ≥ 16 kHz；
- **时长**：每条 3~15 秒为佳。太长（>30s）会被切分阶段处理，
  太短（<2s）在特征提取时容易被质量过滤掉。

### 文本要求

**每个音频要有逐字准确的转写文本。** 这一步没有捷径：

- 错字会被直接学进模型，表现为「某些字读音怪异」，而且事后很难定位；
- 项目支持两种来源：
  1. 音频旁放同名 `.lab` 或 `.txt` 文件（UTF-8 / UTF-8 BOM / GBK 均可识别）；
  2. 交给「语音转文本」阶段自动标注（FunASR 中粤效果好，其它语种走 faster-whisper）。

自动标注之后**建议人工过一遍**：ASR 的错字率通常不高但也不为零。

### 推荐的材料组织方式

```
D:\素材\我的声音\
├── 001.wav
├── 001.lab        # 内容：001.wav 里实际说的那句话
├── 002.wav
├── 002.lab
└── …
```

然后在「模型训练」页直接把目录路径填进「语料目录」，
**关掉「音频切分」与「语音转文本」**（因为文本已经准备好了）。

如果素材是一整段长录音（例如 30 分钟的访谈）：

```
D:\素材\访谈\
└── full.mp3
```

那就**开启「音频切分」+「语音转文本」**，让流水线自动切片并标注，
之后按需在音色库/合成页校对文本。

## 三、跑一次训练

1. 打开「模型训练」；
2. 填「实验名称」（英文数字下划线，会作为输出目录名与权重文件名）；
3. 上传语料，或填写本机目录；
4. 选语料语种与模型版本（**推荐 v2ProPlus**）；
5. 按素材情况开关阶段：
   - 已备好 `.lab` → 关掉「切分」与「语音转文本」；
   - 只有长录音 → 打开「切分」与「语音转文本」；
   - 素材有底噪 → 打开「降噪」；
6. 点「预检计划」，核对每个阶段的命令与参数；
7. 点「开始训练」，观察阶段进度与日志。训练期间可以随时「取消训练」。

> **训练会独占显卡。** 点下「开始训练」后，服务会立刻释放常驻的推理模型
> （日志里会写「正在释放推理模型以让出显存」），训练期间的合成请求会被拒绝并提示
> 「训练正在占用显卡」。这是刻意设计：推理管线与训练脚本各需要一整套模型，
> 在 8GB 级别的消费级显卡上共存必然 OOM。训练结束后，下一次合成会自动重新加载模型。

## 四、参数怎么调

界面暴露的是最常需要动的几个：

| 参数 | 作用 | 建议 |
| --- | --- | --- |
| GPT epoch | 语义模型训练轮数 | 小语料（1~5 分钟）用 15~30；语料多时 8~15 |
| GPT batch | 语义模型批大小 | 显存够就调大；不足时报错就降到 1~4 |
| SoVITS epoch | 声学模型训练轮数 | 8~20。音色相似度主要靠它 |
| SoVITS batch | 声学模型批大小 | 同上 |
| LoRA rank | 仅 v3/v4 生效 | 默认 32；语料很少时可降到 8~16 |
| GPU 编号 | 多卡选择 | 单卡填 `0`；双卡可填 `0-1`（本项目串行执行分片） |

显存不足时的排查顺序：

1. 把两个 batch 都降到 1；
2. 关闭「GPT 训练」，只训 SoVITS（反之亦然）；
3. 降低版本（v2ProPlus → v2Pro → v2）；
4. 训练前先停掉其它占显卡的程序。

## 五、训练产物在哪里

- 权重：`GPT-SoVITS-<版本>/GPT_weights_<版本>/` 与 `SoVITS_weights_<版本>/`
- 数据集与检查点：`trainer/.data/experiments/<实验名>/`
  - `dataset/` — 特征、语义 Token、32k 音频、说话人向量
  - `s1_config.yaml` / `s2_config.json` — 实际使用的配置（可直接复用/微调）
  - `s1_config.log` / `train.log` — 完整训练日志
- 训练页面会在完成后直接列出产物路径。

`if_save_latest` 与 `if_save_every_weights` 默认开启，
因此会同时保留「最新检查点」与「按 epoch 保存的权重」以便挑选。

## 六、训练完成后怎么用

**不需要任何手工切换。** 选择权重时的优先级是
「该版本目录下最新的训练产物 → 官方预训练权重」，
所以只要把「设置 → GPT-SoVITS 本地服务」的默认版本切到对应的版本，
下一次合成就会自动使用刚训好的权重。

想确认当前实际在用哪个权重：

- 设置页会显示「GPT（语义模型）」「SoVITS（声学模型）」的当前文件名；
- `GET /v1/weights` 会返回 `active` 与 `default` 两组信息；
- 训练页的产物路径也可以直接在 `/v1/weights/load` 里手填。

然后到「批量合成」用它生成一批音频做 A/B 比较 ——
换音色、换 epoch 的权重都可以这样并行对比。

## 七、常见问题

**`AssertionError` 出现在 `data_utils.py`**
数据集文件与 `exp_dir` 不匹配。本项目已保证一致；若你手动改了配置，
请确认 `data.exp_dir` 指向包含 `2-name2text.txt` / `4-cnhubert` / `5-wav32k`
（v2Pro 系列还需要 `7-sv_cn`）的那个目录。

**训练在最后一步保存权重时失败**
`<数据集目录>/logs_s2_<版本>/` 不存在。官方 WebUI 会预先创建它，本项目也已处理；
若你改了 `exp_dir`，需要一并保证该目录存在。

**ASR 没识别出任何文本**
检查音频里是否真的是语音、语种设置是否正确、FunASR 是否被用在了非中粤语料上。

**参考音频在 3~10 秒范围外**
这是官方推理期的硬约束。训练用的语料不受此限制，但**做零样本克隆的参考音频必须在范围内**。

**训练很慢 / 显存 OOM**
见第四节。另外注意：训练会独占显卡，期间不要同时做批量合成。

## 八、合规

- 训练他人声音需获得明确授权；
- 禁止用于伪造身份、诈骗、传播虚假信息等违法用途；
- 用公开数据集或社区音色模型训练时，注意其许可证（很多音色模型为 CC-BY-NC-4.0，不可商用）。
